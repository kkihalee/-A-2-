## 케이스별 결과 문장 ('내 말투안')

### 1. status · 재고 실사는 끝났고 차이 조정 중인데 두 건이 원인을 못 찾았어요

- 칸: done=재고 실사는 끝났음 / inProgress=차이 조정 중임 / blocker=두 건이 원인을 못 찾았어요

```
선배님, 진행 상황 공유드립니다.
재고 실사는 끝났습니다. 차이 조정 중입니다. 다만 두 건이 원인을 못 찾았습니다.
```

### 2. request · 오늘 중으로 끝내기 어려워서 내일 오전 10시까지로 미뤄도 될지 인차지님께 여쭤보고 싶어요

- 칸: request=내일 오전 10시까지로 미뤄도 될지 / deadline=내일 오전 10시까지 / reason=오늘 중으로 끝내기 어려움

```
인차지님, 혹시 부탁 하나 드려도 될까요?
내일 오전 10시까지로 미뤄도 될지 여쭙고 싶습니다. 오늘 중으로 끝내기 어렵습니다. 기한은 내일 오전 10시까지입니다.
확인해 주시면 감사하겠습니다.
```

### 3. request · 법인카드 내역 엑셀로 금요일까지 받아야 해요

- 칸: request=법인카드 내역 엑셀로 받아야 해요 / deadline=금요일까지

```
선배님, 혹시 부탁 하나 드려도 될까요?
법인카드 내역 엑셀로 받아야 합니다. 기한은 금요일까지입니다.
```

### 4. question · 매출채권 조회서 회신이 안 와서 대체적 절차로 넘어가도 되는지 궁금해요

- 칸: situation=매출채권 조회서 회신이 안 옴 / ask=대체적 절차로 넘어가도 되는지

```
선배님, 여쭤볼 게 있습니다.
매출채권 조회서 회신이 안 옵니다.
대체적 절차로 넘어가도 되는지 여쭤보고 싶습니다.
```

### 5. question · 내 판단 'A가 전기와 일관됨'

```
선배님, 여쭤볼 게 있습니다.
전기 감가상각 방법 검토 중입니다. 먼저 전기 조서와 당기 계산을 비교해 봤습니다. 다만 정률법 적용 근거를 찾지 못했습니다. 제 판단으로는 A가 전기와 일관된다고 생각합니다.
이대로 진행해도 될까요?
```
